# /review

main.tex をレビューし、reports/ との齟齬、誤字・脱字、表記揺れを報告する。

## コンテキスト
- @CLAUDE.md
- main.tex
- reports/ 内の全ファイル
- references.bib

## 手順
1. reports/ が空の場合は「reports/ にレポートが存在しません」と返し、齟齬チェックを省略する（誤字脱字チェックは続ける）
2. 以下の観点でチェックする

   **A. reports/ との齟齬**
   - 数値・日付・固有名詞（手法名、ツール名、データ件数、評価結果など）の不一致
   - reports/ にない主張や成果を書いていないか
   - 背景・目的・手法・成果の内容が reports/ の説明と食い違っていないか

   **B. 誤字・脱字・表記**
   - 誤字、脱字、変換ミス、助詞の重複（「をを」「のの」など）
   - 表記揺れ（例：「データベース／DB」「行う／おこなう」）
   - 文体の混在（である調とです・ます調）
   - 全角英数字の混入、句読点の不統一

   **C. LaTeX の記述**
   - `\ref{}` に対応する `\label{}` がない、またはその逆
   - `\cite{}` のキーが references.bib に存在しない
   - 残っている `% TODO:` の件数

3. 結果を以下の形式で報告する

   | # | 種別 | 場所（行番号） | 該当箇所 | 指摘内容 | 修正案 |
   |---|---|---|---|---|---|

   - 種別は「齟齬 / 誤字 / 表記 / LaTeX」のいずれか
   - 齟齬については、根拠となる reports/ のファイル名と該当箇所を示す
   - 最後に、種別ごとの件数をまとめる

4. 「修正を適用しますか？（全部 / 番号指定 / しない）」と確認し、承認された分だけ修正する
5. 修正したら `latexmk main.tex` を実行し、ビルドが通ることを確認する

## 注意事項
- 承認されるまで main.tex を編集しない
- 文章表現の好み（言い回しの改善など）は指摘しない。明確な誤りだけを報告する
- 判断に迷うものは「要確認」として別枠で挙げる
- reports/ と docs/ は編集しない
